## 5. How to deliver assets to me

### Option A — Drop into Studio (recommended)
1. Open Studio with the Rojo session connected.
2. Insert the asset (image/mesh/sound/animation) into the appropriate place in the Explorer (e.g., `ReplicatedStorage.Assets.UI.HUD`, `ReplicatedStorage.Assets.Audio.Music`, `ReplicatedStorage.Assets.Models.Weapons`).
3. Rojo syncs it back to the `src/assets/` folder automatically.
4. Tell me the asset name and I'll wire it into the code.

### Option B — Put files directly in `src/assets/`
1. Create `src/assets/{ui,audio,models,animations,textures}/` folders.
2. Drop files there with clear names (e.g., `hud_health_fill.png`).
3. Tell me what you added and I'll import them via Rojo's `$path` or asset IDs.

### Naming convention
- Snake_case, descriptive: `candy_castle_exterior.rbxm`, `hud_health_fill.png`, `music_candy_kingdom_theme.ogg`
- Tier suffix where relevant: `sword_basic`, `sword_rare`, `sword_epic`
